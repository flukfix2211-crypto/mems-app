# เตรียมเครื่อง MEMS ด้วย Siri

นำ migration `20261123034102_siri_voice_prepare.sql` ขึ้นก่อนเปิดใช้หน้าเตรียมเครื่องรุ่นนี้

## ตั้งค่าคำสั่งลัดบน iPhone

1. เปิด MEMS หน้า **เตรียมเครื่องมือ** ด้วยบัญชีเจ้าหน้าที่ เปิด **เชื่อม Siri สำหรับเตรียมเครื่อง** แล้วกด **สร้างรหัสและคัดลอกการตั้งค่า**
2. เปิดแอป **คำสั่งลัด** แล้วสร้างคำสั่งชื่อ **เตรียมเครื่องเมม**
3. เพิ่ม **Text** แล้ววางการตั้งค่าที่คัดลอกมา เพิ่ม **Get Dictionary from Input** เพื่อแปลง JSON จาก Text จากนั้นใช้ **Get Dictionary Value** อ่าน `url`, `apiKey` และ `code` จาก Dictionary เดียวกัน ตั้งชื่อตัวแปรผลลัพธ์เป็น `MEMS URL`, `API Key` และ `Link Code` ตามลำดับ
4. เพิ่ม **Dictate Text** สำหรับรับคำสั่ง ตั้งภาษาไทย และตั้งให้หยุดฟังหลังเว้นจังหวะ เก็บผลเป็น `คำสั่ง`
5. เพิ่ม **Get Contents of URL** ตามค่าของขั้น **ขอทวนรายการ** ด้านล่าง ใช้ **Get Dictionary Value** อ่าน `message`, `status` และ `draft_id` จากผล API จากนั้นใช้ **Speak Text** อ่าน `message`
6. เพิ่ม **If** ตรวจว่า `status` เท่ากับ `preview` ภายในเงื่อนไขใส่ **Dictate Text** ภาษาไทยรอบที่สอง เก็บผลเป็น `คำตอบ` แล้วเพิ่ม **Get Contents of URL** ตามค่าของขั้น **บันทึกหรือยกเลิก** เมื่อได้ผล ให้ใช้ **Get Dictionary Value** อ่าน `message` และ **Speak Text** อ่านข้อความนั้น

ตั้ง **Get Contents of URL** ทั้งสองขั้นให้เปิด `MEMS URL` ใช้เมธอด **POST** กำหนด Header ชื่อ `apikey` เป็นตัวแปร `API Key` และตั้ง **Request Body** เป็น **JSON**

| คีย์ JSON | ขอทวนรายการ | บันทึกหรือยกเลิก |
| --- | --- | --- |
| `p_code` | ตัวแปร `Link Code` | ตัวแปร `Link Code` |
| `p_action` | ข้อความ `preview` | ข้อความ `confirm` |
| `p_text` | ตัวแปร `คำสั่ง` | ตัวแปร `คำตอบ` |
| `p_draft` | เว้นฟิลด์นี้ | ตัวแปร `draft_id` จากขั้นขอทวนรายการ |

เรียก “หวัดดี Siri เตรียมเครื่องเมม” แล้วพูด “เตรียมเครื่องมือ High Flow ให้กับหน่วยงาน ER เบอร์ 12” หรือ “ไฮโฟลว์ เบอร์สิบสอง ให้ห้องฉุกเฉิน” รอให้เครื่องทวนข้อมูล แล้วพูด “ยืนยัน” หรือ “ยกเลิก” คำสั่งลัดจะอ่านผลที่ MEMS ส่งกลับ การบันทึกใช้สิทธิ์บัญชีที่สร้างรหัส ตรวจสถานะเครื่องซ้ำ และใช้ขั้นตอนบันทึกเดียวกับหน้าเว็บ

เก็บคำสั่งลัดที่ใส่ชุดการตั้งค่าแล้วไว้บน iPhone ของเจ้าของบัญชี หากต้องการส่งต่อคำสั่งลัด ให้ลบชุดการตั้งค่าของเจ้าของออกก่อน เครื่องใหม่สร้างรหัสของบัญชีตัวเองจากหน้า MEMS ได้ การสร้างรหัสใหม่จะยกเลิกรหัสเดิมของบัญชีเดียวกัน และมีปุ่ม **ยกเลิกรหัส Siri** ในหน้าเตรียมเครื่อง
